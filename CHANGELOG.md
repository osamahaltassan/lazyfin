# Changelog

All notable changes to Lazyfin are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

- Continue Watching and Next Up list everything a viewer started, however long ago, in every client. Next Up no longer drops shows the viewer has not touched for a year.

## 0.1.1 - 2026-10-25

- The Lazyfin plugin repository now offers Lazyfin. The 0.1.0 release build failed before it reached the repository, so this is the first version admins can install, and it carries everything listed under 0.1.0.

## 0.1.0 - 2026-10-25

- Admins can install Lazyfin on Jellyfin 12.x from the Lazyfin plugin repository, where the catalog shows the Lazyfin icon.
- Right-to-left subtitle lines, such as Arabic, show their end punctuation at the end of the line, in the web player, the iOS app, and burned-in video.
